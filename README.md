# React Todo List

A basic React todo list app built with Vite for learning core React concepts like state, events, rendering, and local storage.

## Features

- Add new todo items
- Mark todos as complete
- Delete todo items
- Persists todos in local storage

## Getting Started

```powershell
npm install
npm run dev -- --host 127.0.0.1
```

Open the app in your browser at `http://127.0.0.1:5173/`.

## Build

```powershell
npm run build
```
